# Продолжение разработки

Текущая версия: 0.2.0, ветка feat/dock-behavior. Исходники восстановлены из переданного пользователем архива версии0.1.0; исправления runtime packaging r2 восстановлены отдельно в scripts/bundle-launch и scripts/runtime-check.c.

В поставляемом ZIP дополнительно находится development-history.bundle — локальная Git-история. При утрате рабочего каталога её можно восстановить:

```sh
git clone development-history.bundle restored-mosaic
cd restored-mosaic
```

Локальная рабочая ветка не синхронизирована с GitHub. Репозиторий GitHub ещё не создан; не добавляйте выдуманный remote и не объявляйте push выполненным. Для первого remote потребуется создать приватный репозиторий в подтверждённом аккаунте пользователя.

Пользователь попросил временно не писать и не запускать тесты. Разрешены cargo check/build и форматирование; runtime проверка отдельно. Возобновление тестов требует изменения этой пользовательской инструкции.
