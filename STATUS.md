## Доказательства проверки

- Rust 1.90.0, GTK4 4.18.6, gtk4-layer-shell 1.0.4 в локально подготовленном Debian toolchain.
- `cargo build --workspace`, `cargo test --workspace`, `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets -- -D warnings` — см. итоговый verification report.
- Nix 2.26.3: `flake lock`, `flake check --no-build`; зафиксирована ревизия nixpkgs.
- Python regression test session cleanup с подставными командами; это тест lifecycle-логики, не настоящего systemd-сеанса.
- Попытка D-Bus integration smoke заблокирована средой: `Failed to open socket: Operation not permitted`. Тест НЕ считается пройденным.
- Попытка headless Labwc 0.8.3 остановилась при создании XWayland display. Полноценный GUI/Wayland прогон НЕ выполнен.
- NixOS пользовательской машины, GPU и совместимость её Labwc ещё неизвестны. Нельзя объявлять этап 0 завершённым.

## Решения и замечания ревью

- Разработка начата в отдельном новом репозитории и feature-ветке; исходного репозитория пользователя не было.
- Фокус текущей поставки — первый срез, не весь выпуск 1.0. Все большие отсутствующие части перечислены выше.
- Исправлены: ненулевой exit status при startup error; очистка DISPLAY/WAYLAND activation environment; сохранение только изменённых overrides; повторное использование CSS provider; наблюдаемое закрытие при переполнении live notifications.
- Изменение `dock.margin` / `panel.height` через reload пока требует перезапуска UI; тему и размер иконок можно менять без перезапуска. Это отложенное небольшое замечание ревью.
