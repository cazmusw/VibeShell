# Импорт исходников 0.2.0

Исходники восстановлены из переданного пользователем mosaic-shell-0.2.0-sources(1).zip.
Сохранены актуальные .github/workflows/build.yml и scripts/export-nix-package.sh из VibeShell. Старый workflow архива не переносится, чтобы не запускать параллельные pipelines. Вложенный Git bundle в приложение не импортируется.

Дополнительно подготовлено исправление scripts/bundle-launch: при недоступном постоянном кэше используется новый приватный временный каталог в XDG_RUNTIME_DIR/TMPDIR. Программа не меняет владельца и права каталогов пользователя. Это исправляет блокирование запуска на root-owned кэше; сам старый каталог не удаляется. Временный каталог остаётся для работы отложенного загрузчика изображений; дальнейшую очистку выполняет система runtime/tmp.

Тесты не добавлялись и не запускались по указанию пользователя. Проверен только shell syntax. Компиляция текущего импорта и реальный запуск пока не проверены.

Пользователь явно подтвердил публичную публикацию 16 ноября 2026. Импорт отправляется в cazmusw/VibeShell с сохранением актуального CI/CD.
