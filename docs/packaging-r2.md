# Runtime data переносимого пакета

Обновления r2 восстановлены из прикреплённого бинарного архива. scripts/bundle-launch задаёт XKB_CONFIG_ROOT, XLOCALEDIR и LOCPATH относительно каталога пакета, а также отказывает в запуске GUI от root. В переносимую сборку обязательно входят данные share/X11/xkb, share/X11/locale и совместимые с включённой libc локали share/locale-runtime (C.utf8, ru_RU.utf8, en_US.utf8).

scripts/runtime-check.c — уже существующая диагностическая утилита из r2, не новый тест. На данном этапе она не запускается по просьбе пользователя. Исправление данных XKB не доказывает устранение исходного segfault; графический запуск и backtrace при повторении по-прежнему нужны.

Исходный archive не содержал packaging updates r2; они восстановлены как отдельные scripts, Rust UI source не заменён бинарниками. Ранее успешно собранный Nix derivation не объявляется доступным в текущей восстановленной среде.
