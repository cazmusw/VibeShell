# Dock: следующая итерация

Основа: утверждённое ТЗ, D07–D10. Пользователь явно попросил пока не писать и не запускать тесты. Выполняются cargo check/build и форматирование; runtime-поведение не считается проверенным без Labwc.

1. Восстановить source archive, сохранить отдельный feature branch, перенести launch/runtime data fix r2 в packaging scripts.
2. Добавить валидируемые параметры Dock: autohide, show/hide delays (150/700 ms), magnification (1.45), maximum width ratio (0.9).
3. Вынести поверхности, таймеры и меню Dock в отдельный контроллер. Автоскрытие без reserved zone, edge sensor не перехватывает клавиатуру. Открытое меню и фокус клавиатуры удерживают Dock видимым.
4. Фиксированные области кнопок и отдельная отрисовка иконок с плавным изменением размера: соседние targets не сдвигаются при наведении. Tick callback действует только до достижения цели; reduced motion отключает увеличение.
5. Ограничить ширину viewport монитором, добавить прокрутку колесом и кнопками. Добавить shellctl dock show через D-Bus и параметры в GUI.
6. Применять геометрию Dock на reload; записать ограничения (нижнее расположение, без IntelliHide и hotplug).
7. Проверить компиляцию, без тестов. Сохранить source archive. GitHub push остаётся заблокирован до разрешения входа через Google/предоставления доступного репозитория.
