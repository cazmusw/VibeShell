# Dock 0.2: реализация и ограничения

Добавлены собственный Gtk Widget для отрисовки иконки, отдельный контроллер Dock, edge surface, таймеры autohide, прокручиваемый viewport и D-Bus команда ShowDock. Фиксированные allocation иконок учитывают максимальный размер: наведение не меняет hit targets и не запускает пересчёт размеров строки. Frame callback работает только до приближения к целевому масштабу. Reduced motion отключает увеличение.

Режим по умолчанию остаётся «всегда виден». Для автоскрытия:

```toml
[dock]
autohide = true
show_delay_ms = 150
hide_delay_ms = 700
magnification = true
magnification_factor = 1.45
max_width_ratio = 0.9
```

Параметры доступны через TOML/Home Manager; автоскрытие, включение/сила увеличения — также через GUI. Изменения Dock применяются при сохранении или `shellctl reload`, включая нижний отступ и exclusive zone. Strict-режим остаётся read-only.

В скрытом режиме место под Dock не резервируется. На нижнем крае остаётся поверхность высотой 2 логических px. Показ и скрытие имеют задержки; сам переход видимости пока мгновенный, без анимации slide/fade. Между sensor и Dock сохраняется настроенный margin; скрытие откладывается, чтобы указатель успел пройти этот промежуток. Sensor и Dock не запрашивают клавиатуру при обычном наведении.

`shellctl dock show` явно вызывает Dock и запрашивает клавиатурный фокус; Escape завершает этот режим. Открытое меню удерживает Dock. Изменения списка окон откладывают перестройку до закрытия меню; команды всё равно проверяются backend по epoch/id.

Ширина viewport ограничена долей логической ширины монитора. При переполнении доступны колесо/горизонтальная прокрутка и кнопки слева/справа. По умолчанию лимит 90%. Размер иконок не уменьшается автоматически: сначала применяется configured size, затем прокрутка.

За рамками этой итерации: боковые положения, IntelliHide по геометрии окон, отдельная fullscreen-политика, hotplug и маршрутизация на preferred output, drag-and-drop закреплений. Настройки panel.height по-прежнему требуют перезапуска.

По прямой просьбе пользователя новые тесты не создавались и существующие не запускались. CI содержит только `nix build`, package doCheck=false. Проверяются cargo check/build и форматирование. Runtime под реальным Labwc, визуальная плавность, фокус клавиатуры и производительность пока не проверены. Предыдущие отчёты о тестах относятся только к исторической версии 0.1.
