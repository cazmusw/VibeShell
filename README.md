# VibeShell

Rust/GTK4 desktop shell for Labwc and NixOS, continued from Mosaic Shell.

CI/CD configuration is prepared. **Application source import is still pending**;
until Cargo.toml, Cargo.lock, flake.nix and flake.lock are present, the workflow
explicitly skips the application build. No application binaries have been built
by this repository yet.

See [docs/CI-CD.md](docs/CI-CD.md) for build artifacts and draft releases.
